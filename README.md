# Kaspi Bot — лендинг

Многоязычный сайт сервиса **Kaspi Bot** для автоматизации продаж на Kaspi.kz. Лендинг знакомит продавцов с возможностями сервиса, показывает интерфейс и позволяет оставить номер телефона для подключения.

Сайт: [bot.alixan.kz](https://bot.alixan.kz).

## Возможности сайта

- Главная страница с описанием сервиса, инструкцией по подключению, контактами и ответами на частые вопросы.
- Отдельные страницы о демпинге цен, синхронизации товаров, управлении остатками, нескольких магазинах, заказах в Telegram и аналитике продаж.
- Русская, казахская и английская локализации.
- Светлая, тёмная и системная темы оформления.
- Форма заявки с проверкой номера телефона и отправкой во внешний API.
- Страницы политики конфиденциальности и пользовательского соглашения.
- SEO-метаданные, Open Graph и автоматическая генерация sitemap.

## Технологии

Nuxt 4, Vue 3, TypeScript и Tailwind CSS 4. Для локализации используется `@nuxtjs/i18n`, для переключения темы — `@nuxtjs/color-mode`, для слайдеров и анимаций — Swiper и Lottie, для иконок — Lucide.

## Локальный запуск

Используйте Node.js 22 и npm — эта версия Node.js также используется в CI.

```bash
npm ci
npm run dev
```

Сайт будет доступен по адресу `http://localhost:5100`.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запуск сервера разработки |
| `npm run build` | Сборка приложения для production |
| `npm run generate` | Генерация статического сайта в `.output/public` |
| `npm run preview` | Локальный просмотр production-сборки |

## Структура проекта

```text
app/
  assets/        # Стили, изображения и Lottie-анимации
  components/    # Секции лендинга и UI-компоненты
  composables/   # Управление диалогами, формами и метаданными
  config/site/   # Домен, контакты и настройки сайта
  layouts/       # Общий макет страниц
  pages/         # Главная, страницы возможностей и правовые документы
  utils/         # Вспомогательные функции
i18n/
  configs/       # Настройки переводов
  locales/       # Переводы ru, kk и en
public/          # Статические файлы, иконки и Open Graph-изображение
.github/workflows/pages.yml  # Сборка и публикация на GitHub Pages
nuxt.config.ts   # Конфигурация Nuxt и модулей
```

## Настройка

- Тексты сайта находятся в `i18n/locales/ru.json`, `kk.json` и `en.json`.
- Домен, название сервиса и контакты задаются в `app/config/site/site.ts`.
- Русские страницы доступны без языкового префикса, английские — с `/en`, казахские — с `/kk`.
- Форма в `app/components/app/send-form/SendFormDialog.vue` отправляет `POST` на `https://kaspibot-api.alixan.kz/api/landing/leads` с телом `{ "phone": "+7XXXXXXXXXX" }`. При подключении другого backend измените адрес API в этом компоненте.

## Публикация

GitHub Actions автоматически выполняет `npm ci` и `npm run generate` при push в ветку `main`, затем публикует содержимое `.output/public` на GitHub Pages. Workflow также можно запустить вручную через `workflow_dispatch`.

Для собственного домена проверьте файл `CNAME` и адрес сайта в `app/config/site/site.ts`.
